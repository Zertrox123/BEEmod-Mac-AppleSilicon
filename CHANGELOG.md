# Changelog

## 1.0.0

- One-step installer for BEEmod 4.36 on Apple Silicon (Rosetta 2).
- Tcl/Tk 8.6.10 in place of BEEmod's 8.6.8 (blank windows on current macOS).
- `games.cfg` written automatically (BEEmod's picker only accepts `.exe`).
- Map compiler hook: BEEmod's VBSP/VRAD run through Portal 2 Natif's native
  compilers; Build and Play and Workshop publishing work with BEEmod items.
- `Portal 2 Natif.app` patcher (launcher hook, palette icon fix) and the same
  change as a patch for source-recomp checkouts.
- `BEEmod.app` launcher and an uninstaller.
